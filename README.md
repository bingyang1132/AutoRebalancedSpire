# 平衡尖塔适配 · AutoRebalancedSpire

[English](README.en.md)

让**杀戮尖塔2自动战斗求解器**适用于**平衡尖塔**。

装了平衡尖塔之后，牌组里只要有它改过的 33 张牌里的任意一张，求解器就会拒绝规划整场战斗。
本 Mod 装上之后求解器照常工作。不改变任何游戏行为和数值（清单里 `affects_gameplay` 是
`false`）。

## 需要装什么

| 依赖 | 版本要求 | 说明 |
|---|---|---|
| 自动战斗求解器（CombatSolver） | **至少 0.38.2** | [创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3790899961) ／ [GitHub](https://github.com/Torch1230/CombatSolver) |
| 平衡尖塔（RebalancedSpire，作者 ty / Oroboro） | **v0.3.10-beta** | [创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3747498062) |
| RitsuLib | 0.6.0 起 | [创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3747602295) |

**版本不对会怎样：**

- 求解器低于 0.38.2，或者缺了某个登记入口 → 本 Mod **干净地拒绝加载**，日志里写明缺什么。
  求解器会照常停在它自己那道第三方检查上，也就是回到没装本 Mod 的样子。
- 平衡尖塔换了版本 → 本 Mod 仍然加载，但日志里会写「这一份平衡尖塔不是逐条核对过的那一版」。
  **这句话要当真**：它改过的每一张牌都是一个直接替换打出效果的补丁，换版本等于换实现，
  数值和语义的漂移结构自检抓不到。

## 两个版本

**求解器还在持续开发，本 Mod 也会相应持续更新。** 适配层是贴着求解器的内部接口写的，
求解器一改，适配层就可能得跟一次。所以这里分两条线发布：

| 版本 | 对标 | 从哪拿 |
|---|---|---|
| **创意工坊版** | 求解器的**发布版**（0.38.2 起） | [创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3803035225) 订阅即可 |
| **GitHub 版** | 某一个确定的求解器版本，可能是开发版 | [Releases](https://github.com/bingyang1132/AutoRebalancedSpire/releases) |

## 覆盖了什么

- **被换掉打出效果的 33 张牌**逐张核对镜像，按反编译出的实现写，不是照着卡面文字猜
- **带选牌的那四张**是真正的搜索分支：降灵、传承之锤、手上技法、隐秘匕首，选哪几张由求解器自己搜
- **改过的怪物招式**：换了 id 的 26 条里有效果的都接管了，另有 10 条数值或效果被改写的也补齐
  ——同族小队、组装师、灵魂枢纽、无厌沙虫、胧光怪、残杀千足虫、异蛙寄生虫这些都在内
- **新加的 33 个 Power** 里 32 个有镜像，4 个新病症、2 个新附魔、2 张新牌、3 瓶新茶也都覆盖
- **7 个战斗内遗物**：轰鸣海螺、钻石头冠、十字弓、选择悖论、小提琴、历史课、低语耳环
- **全局规则**：覆甲衰减、会变的手牌上限、回合结束的保留与弃牌选择

## 已知缺口

有 1 处：

- **门扉缔造者**（平衡尖塔新加的第三章 Boss）。它关着门的时候用一条假血条挡住选中，求解器没有
  「血条是假的」这个概念，要跟上得先改求解器本身。它**不会静默算错**——求解器会把它的出招标成
  「不支持」，只打红字，不会给一条看起来可信的错路线。建议在平衡尖塔的设置里关掉它，关掉之后
  它不进第三章 Boss 池，连带的随机目标改写和「万物动力学」也一起不生效。

本 Mod 只在加载时提醒一次，不替你改设置。

逐类普查（牌、怪物招式、Power、遗物、药水／状态牌／病症／附魔／新牌）在
[docs/coverage-gaps.md](docs/coverage-gaps.md)，每条都标了后果分级。

## FAQ

**装了本 Mod，求解器还是停在「检测到不兼容的第三方 Mod」？**
说明适配层没有加载。日志里 `[AutoRebalancedSpire]` 开头那几行会写明原因，最常见的是求解器版本
低于 0.38.2。适配层是全有或全无：前提不成立就一个镜像都不注册，绝不装一半——放行了牌却没有
镜像，比拒绝整场战斗糟得多。

**为什么求解器一定要 0.38.2 以上？**
平衡尖塔改过的那 33 张牌要登记进求解器的适配入口，求解器才知道「这张牌被人换过实现，但有人
按新实现写了镜像」。那个入口（`AdaptedCardOnPlayMirrors`）是 `0.38.2` 第一次进发布产物的，
低于它连类型都找不到。

**平衡尖塔更新之后还能用吗？**
它改过的每一张牌都是直接替换打出效果的补丁，换一版就等于换一份实现。所以本 Mod 钉的是
v0.3.10-beta，对着别的版本运行时日志里会写明。看到那句话又觉得路线不对，请报 Bug，我会跟版本。

**在平衡尖塔的设置里把某张牌关掉了，求解器会怎么算？**
关掉等于那张牌回到原版语义，求解器按原版算，是对的。但开关是在进游戏时读一次的：中途改了开关，
本 Mod 会发现登记时的状态和现在对不上，于是不放行——求解器停在第三方检查上，而不是拿着一份
过期的镜像继续算。改完开关重开游戏即可。

**工坊版和 GitHub 版可以混着装吗？**
不要。混了也不会静默出错——结构自检对不上就拒绝加载——但没必要。出了问题优先看你装的是哪一对。

## 从源码构建

```bash
dotnet build AutoRebalancedSpire.csproj -c Release
```

构建会把 DLL 和清单复制到 `<游戏目录>/mods/AutoRebalancedSpire/`。前提是
`mods/CombatSolver/CombatSolver.dll` 和 `mods/RebalancedSpire/RebalancedSpire.dll` 都已存在；
路径不对可以放一份 `local.props` 覆盖。本仓库不包含任何第三方二进制。

验收矩阵是 `tools/run-rebalanced-matrix.ps1`（30 条端到端夹具，跑在求解器自带的无头 harness
上）。**它会杀掉正在运行的游戏进程**，别在玩的时候跑。
