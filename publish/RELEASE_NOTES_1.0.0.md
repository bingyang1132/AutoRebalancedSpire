# AutoRebalancedSpire 1.0.0

让自动战斗求解器适用于平衡尖塔（RebalancedSpire）。

对标：求解器 **0.40.1**（工坊版），平衡尖塔 **v0.3.10-beta**（Workshop 3747498062，
DLL SHA256 `cce7a199…dcd2b`），游戏 0.111.0，RitsuLib 0.6.x。
清单里求解器最低版本写的是 **0.38.2**，那是结构下限——`AdaptedCardOnPlayMirrors` 从那一版起
进发布产物，本适配层用到的其他求解器 API 在那一版也都在。**实际验证过的只有 0.40.1。**

## 解决的问题

装了平衡尖塔之后，牌组里只要有它改过的 33 张牌里的任意一张，求解器在建根时就抛
`IncompatibleGameplayModException`，整场战斗一步都不规划。这是求解器该有的行为：它按原始
未打补丁的 IL 推断打出效果，牌被换了实现而它照原样算，出来的是一条实机不会那样打的路线。

本 Mod 把这 33 张牌逐张镜像后登记进求解器的适配入口，于是求解器知道自己算得对，放行。

## 覆盖

- 33 张被换掉打出效果的牌，按反编译出的实现逐张写。其中 4 张带选牌分支（降灵、传承之锤、
  手上技法、隐秘匕首），是真正的搜索分支。
- 平衡尖塔新增的 33 个 Power 里 32 个有镜像；4 个新病症、2 个新附魔、2 张新牌、3 瓶新茶。
- 怪物招式：改版换了 id 的 26 条里有效果的都接管了，另外 10 条数值或效果被改写的也补齐了。
- 7 个战斗内遗物：轰鸣海螺、钻石头冠、十字弓、选择悖论、小提琴、历史课、低语耳环。
- 全局规则：覆甲衰减、会变的手牌上限、回合结束的保留与弃牌选择。

## 已知缺口

**门扉缔造者（Doormaker）**，平衡尖塔新加的第三章 Boss，没有适配。它「关着」的时候把自己的
最大和当前生命都设成 999999999、用假血条挡住选中，求解器没有「血条是假的」这个概念，
要镜像得先在求解器里造一套生命遮罩机制。

后果是那一场用不了，不是算错：求解器把它的出招标成「不支持」，只打红字。建议在平衡尖塔的
设置里关掉它。本 Mod 只在加载时提醒一次，不替玩家改设置。

## 验收与证据

- 30 条端到端夹具（`tools/run-rebalanced-matrix.ps1`），跑在求解器自带的无头 harness 上。
  每条都要求「只有镜像正确才能通过」。
- 最近三条新夹具各做过反向对照（注掉登记立刻挂，恢复即过）。
- **全量 30 条对着 0.40.1 跑过一轮**：29 通过、1 未通过。未通过的 `RS-KIN-SUMMON-HP` 是夹具
  自己少给了敌人血量（harness 默认 1 血，那一场第一回合就结束，断言的第 2 回合不存在），
  补上之后正向通过、反向对照如期挂掉。**改完只重跑了这一条，没有再跑一轮全量。**
- **来生的动态变量这一处没有回归夹具。** 求解器只打能减掉血的牌，而奥斯提满血时来生的治疗量
  是 0 收益，无头 harness 又没有能让奥斯提掉血的旋钮。这一处的证据是三份实机问题包的数值
  对照（预测 `[Heal=0,Summon=-1]` 对实机 `[Heal=4,Summon=3]`）和反编译，没有回归证据。
- 原版角色在没装平衡尖塔时的行为不受本 Mod 影响（本 Mod 不加载就什么都不注册），
  但这一版也没有原版角色的回归证据。
